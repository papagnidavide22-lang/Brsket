# Contributing

Brsket's source code is not public, but there are several ways to help.

## Report a bug

[Open a bug report](../../issues/new?template=bug_report.yml) and include:

- Brsket version (Brsket › About Brsket), Mac model and macOS version;
- the link or the kind of file involved;
- what you did, what you expected and what happened.

Remove anything private from links and logs before posting them.

## A site stopped working

Sites change often. First check that you have the [latest release](../../releases/latest).
If the problem is still there, report the site and the message Brsket shows.

## Suggest a feature

[Open a feature request](../../issues/new?template=feature_request.yml). Tell us the
problem you want solved, not only the solution.

## Translations

Brsket's interface is in Italian. If you would like it in your language, open a feature
request.
